자주 묻는 것

명령을 어떻게 치나요

초반 임무는 화면 아래 칩을 누르면 명령이 완성됩니다. 뒤로 가면 키보드로 직접 칩니다. 막히면 입력줄 옆 ? 단추로 쓸 수 있는 명령을 보고, 위쪽 힌트를 쓰세요(힌트를 쓰면 별이 줄어듭니다).

명령이나 비밀번호가 틀렸다고 나와요

명령과 비밀번호는 모두 영어입니다. 한글 자판이면 영어 자판으로 바꿔 치세요.

추적당해서 실패했어요

시작 서버 밖에 오래 머물면 추적 게이지가 오르고 100%면 실패합니다. 상점에서 추적 교란기를 사면 늦출 수 있습니다.

브리치 퍼즐 규칙이 헷갈려요

맨 윗줄에서 하나 → 그 세로줄에서 하나 → 그 가로줄에서 하나… 번갈아 골라, 고른 코드로 목표 순서를 만듭니다. 1단계는 따라 하기 연습판입니다.

언어를 바꾸고 싶어요

설정 → 언어에서 한국어·영어 중 고르거나, 기기 언어를 따르게 할 수 있습니다.

기록을 지우고 처음부터 하고 싶어요

설정 → 진행 초기화. 기록은 기기 안에만 저장되고 서버로 올라가지 않습니다. 자세한 내용은 개인정보처리방침을 보세요.

Frequently asked

How do I type commands?

In early missions, tap the chips under the terminal to build each command. Later you type on the keyboard. If you're stuck, the ? button next to the input line lists the commands, and Hint at the top helps (hints cost stars).

It says my command or password is wrong

All commands and passwords are in English. Switch your keyboard to English if needed.

I got traced and failed

Staying outside your start server raises the trace meter; at 100% the run fails. The trace scrambler in the shop slows it down.

The Breach rules are confusing

Pick one code in the top row → one in that column → one in that row… alternating, to build the target sequences. Stage 1 is a guided practice board.

How do I change the language?

Settings → Language — Korean or English, or follow the device language.

How do I start over?

Settings → Reset progress. Progress stays on your device and is never uploaded. See the privacy policy for details.
