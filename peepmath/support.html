자주 묻는 것

연습장은 어떻게 쓰나요

문제 화면 위쪽의 연습장 버튼을 누르면 문제 위에 바로 그릴 수 있습니다. 색을 고르고, 지우개로 지우고, 되돌리기도 됩니다. 다 썼어요를 누르면 닫히고, 다음 문제로 가면 저절로 지워집니다.

답이 분수인데 어떻게 쓰나요

3/4 처럼 빗금으로 쓰면 됩니다. 0.75 로 써도 맞습니다. 단위가 있는 문제는 숫자만 써도 됩니다 (12 cm 대신 12).

학년이 안 열려요

앞 학년을 어느 정도 끝내면 열립니다. 지금 실력에 맞는 학년부터 시작하고 싶으면 홈 화면의 레벨테스트를 보세요 — 결과에 맞는 학년까지 한 번에 열립니다.

앱 언어를 바꾸고 싶어요

설정 → 언어에서 고르면 됩니다. 폰 전체 언어를 바꾸지 않아도 됩니다. ‘기기 설정 따름’을 고르면 폰 언어를 따라갑니다.

다음 레슨이 안 열려요

앞 레슨을 먼저 끝내야 열립니다. 순서와 상관없이 아무 레슨이나 풀고 싶으면 설정 → 자유 이동 모드를 켜세요.

하트가 다 떨어졌어요

시간이 지나면 저절로 찹니다. 기다리기 싫으면 상점에서 채울 수 있고, 아예 설정 → 하트 쓰기를 꺼 두면 틀려도 줄지 않습니다.

힌트가 안 눌려요

힌트는 4지선다 문제에서만 쓸 수 있고, 한 문제에 한 번만 됩니다. 개수가 0이면 상점에서 살 수 있습니다.

용돈은 진짜 돈인가요

아닙니다. 앱 안에 저장된 숫자입니다. 실제로 돈을 주고받는 것은 이용자들 사이의 약속이고, 앱은 결제를 처리하지 않습니다. ‘현금으로 바꾸기’는 그 숫자를 줄이고 기록을 남기는 기능이며, 설정에서 PIN을 걸어 두면 함부로 누를 수 없습니다.

기록을 지우고 싶어요

설정 → 진행도 전체 초기화를 누르면 전부 지워집니다. 앱을 삭제해도 지워집니다. 다만 안드로이드 자동 백업이 켜져 있으면 지웠다가 다시 깔 때 예전 기록이 돌아올 수 있습니다 — 기기 설정 → Google → 백업에서 끌 수 있습니다.
