## 3. 데이터 보안 (Data safety) 신고

앱이 실제로 하는 일 그대로 신고하면 된다. **거짓으로 적으면 정지 사유**다.

| 항목 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | **아니요** |
| 데이터가 전송 중 암호화되나요? | 해당 없음 (전송 자체가 없음) |
| 데이터 삭제를 요청할 수 있나요? | 해당 없음 (수집하지 않음) |

근거: 앱에 `INTERNET` 권한이 없다. 요청하는 권한이 아예 없다.
저장하는 값(별·힌트·설정)은 기기 안에만 있고 서버가 존재하지 않는다.

> 다만 안드로이드 **자동 백업**은 켜져 있다(기본값). 이용자 본인의 Google 드라이브로
> 가는 OS 기능이라 "개발자의 데이터 수집"에는 해당하지 않지만,
> 개인정보처리방침에는 명시해 두었다.

## 4. 광고 · 콘텐츠 등급

| 항목 | 답 |
|---|---|
| 광고 포함 | **아니요** |
| 인앱 구매 | **아니요** |
| 타깃 연령 | 전체 이용가 |
| 콘텐츠 등급 설문 | 폭력·성적 내용·욕설·약물·도박 **전부 없음** → 3+ / 전체이용가 |
| 이용자 간 소통 기능 | 없음 |
| 위치 공유 | 없음 |

**어린이 대상 앱(Families) 프로그램**: 그림체가 유아 친화적이라 "어린이와 성인 모두"
(Mixed audience)로 신고하는 편이 안전하다. "주로 어린이 대상"으로 신고하면
Families 정책 심사가 추가로 붙는다.

> **광고나 인앱결제를 붙이는 날 같이 고쳐야 하는 것** — 문구만 고치면 되는 게 아니다.
> 신고 내용과 앱이 달라지면 앱이 내려간다.
>
> | 고칠 곳 | 무엇으로 |
> |---|---|
> | `AndroidManifest.xml` | `INTERNET` 권한 추가 (지금은 권한이 0개다) |
> | 위 **3. 데이터 보안** | 광고 SDK는 광고 식별자(AAID)·기기 정보를 읽는다 → "수집함" |
> | 위 **4. 광고·콘텐츠 등급** | 광고 포함 **예** / 인앱 구매 **예** |
> | `privacy.html` | 광고 제공자가 무엇을 읽는지 명시 |
> | `index.html` · `support.html` | 남아 있는 "인터넷을 쓰지 않는다" 류 문구 |
> | 등록정보 13개 언어 | **손댈 것 없다** — 애초에 그런 말을 안 썼다 |
>
> 순서: 개인정보처리방침을 **먼저** 갱신하고, 그다음 광고가 든 빌드를 올린다.

## 5. 그래픽 자산 (직접 만들어 올려야 하는 것)

| 자산 | 규격 | 필수 |
|---|---|---|
| 앱 아이콘 | 512 × 512 PNG (32비트, 알파 없음) | 필수 |
| 그래픽 이미지 | 1024 × 500 PNG/JPG | 필수 |
| 휴대전화 스크린샷 | 최소 2장, 16:9 또는 9:16, 320~3840px | 필수 |
| 태블릿 스크린샷 | 7인치·10인치 | 선택 |

**다 찍어 뒀다.** 13개 언어 × 7장, 게임 저장소의
`store/업로드/스크린샷/<언어>/` 에 있다. 콘솔에서 언어를 고른 뒤
그 언어 폴더의 7장을 순서대로 올리면 된다.

순서 (게임의 특징이 드러나는 차례)

1. 타이틀 — 병아리와 메뉴
2. 챕터 목록 — 20챕터가 쭉 보이는 화면
3. 얼음 판 — 알이 미끄러지는 기믹
4. 힌트를 켠 화면 — 갈 곳이 번호 1~5로
5. 단추와 문
6. 클리어 팝업 — 별 3개
7. 오늘의 퍼즐과 달력

다시 찍으려면 폰을 연결하고 게임 저장소에서:
```bash
python tool/shoot_all_langs.py && python tool/prep_screenshots.py
```
